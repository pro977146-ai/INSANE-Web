01 · Hardware
CPU architecture, explained properly


Every program you run is a stream of instructions flowing through the same stages. Watch the pipeline in motion.


FETCHread instr.
DECODEmicro-ops
EXECUTEALU / FPU
MEMORYload / store
WRITE-BACKregisters




01
Pipelining & superscalar
Stages overlap so many instructions are in flight, and wide cores issue several per cycle across parallel units.


02
Out-of-order & speculation
The CPU reorders work around stalls and predicts branches. Wrong guesses roll back, but can leave traces in caches, the root of Spectre.


03
Cache hierarchy
L1 answers in about a nanosecond, RAM in around eighty. Locality of access often matters more than raw clock speed.


04
Virtual memory
Page tables and the TLB translate addresses, giving every process isolation while the kernel keeps control.


05
Privilege rings
User and kernel modes are enforced by hardware. System calls are the controlled doorway between them.


06
Multicore & SMT
Cores, hyper-threads and coherence protocols share caches and buses, which is where races and side channels hide.

home-lab.sh
# refresh the system
$ sudo apt update && sudo apt full-upgrade -y
# scan YOUR OWN lab VM on a host-only network
$ nmap -sV -T3 192.168.56.101
# see what your machine is listening on
$ sudo ss -tulpn


Practise legally: run Kali plus a deliberately vulnerable target (Metasploitable, DVWA or Juice Shop) in VirtualBox on an isolated network, or use TryHackMe, Hack The Box and picoCTF.







04 · Defense
Cybersecurity fundamentals


Think like an attacker, build like a defender.




C·I·A
The CIA triad
Confidentiality, integrity and availability are the goals every control serves.


W10
OWASP Top 10
Injection, broken access control, cryptographic failures and misconfiguration: the web baseline.


MEM
Memory safety
Overflows and use-after-free come from CPU fundamentals. Fight them with ASLR, NX, canaries and Rust.


KEY
Cryptography
Use vetted libraries: AES-GCM, ChaCha20, Ed25519 and Argon2. Never invent your own.


DiD
Defense in depth
Least privilege, patching, MFA, segmentation, logging and monitoring.


IR
Incident response
Prepare, detect, contain, eradicate, recover, learn. Logs are your memory.
